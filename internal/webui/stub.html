The web UI is not built into this binary

This local-server binary was built with a plain go build, so it holds this page instead of the web UI. The API answers as usual.

To get the web UI, build from the source tree with make build. It builds the web UIs first (the admin UI with make web-admin-build and the consumer web page with make web-consumer-build, which need Node.js and npm) and then the binary.
