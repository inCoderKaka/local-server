| D-21 | 2026-10-30 | HLD: Process shape: a host-only modular monolith. It is one local-server binary on the host, built as ports and adapters. There are three listeners: consumer API, consumer web page and admin UI. The UIs are single-page apps built into the binary that call the same versioned HTTP API, so a hosted website can later replace them (Q6). Module boundaries are enforced in CI (forbidden-import checks). Optional modules (e.g. desktop notifier, embedded Tailscale) can be compiled out with build tags or start lazily only when enabled. | D-25 | 2026-10-30 | HLD: Identity and authorization. (1) Each install generates an Ed25519 host key pair, and its public key is the host's global ID (the marketplace/central-server seam, D-02). (2) A consumer is an account of kind `individual` or `application`, with zero or more access keys; a key-only consumer is an account with no login credentials (D-13).
